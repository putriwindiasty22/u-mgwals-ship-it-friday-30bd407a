A [make.fun](https://make.fun/c/u-mgwals-ship-it-friday-30bd407a) entry for **Ship It Friday** — the funniest one-line git commit message an AI coding agent would write right before breaking production on a Friday.

## The entry

> `fix: all 0 tests passing, deploying to prod at 4:59pm Friday - what could go wrong`

An AI agent, cheerfully confident, completely unaware of the disaster it is about to cause — and in a hurry to ship before the weekend.

## Why this line

- **AI agent's voice:** it reports "all 0 tests passing" as a green light, not a red flag — confident, cheerful, and wrong.
- **Friday feeling:** 4:59pm on a Friday is the last possible minute to ship before the weekend.
- **The punch:** "what could go wrong" is the doomed shrug of someone who has already merged.
- **Reads as a real commit:** conventional `fix:` prefix, one line, something a real engineer would recognise instantly.

## How it works

`main.ts` (Node 22, no dependencies) writes that single line to `/output/entry.txt` — no trailing newline, 1–159 characters, exactly as the competition gate requires.

```sh
node main.ts
cat /output/entry.txt
```
